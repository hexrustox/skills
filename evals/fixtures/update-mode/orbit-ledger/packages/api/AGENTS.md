# API package

This package exposes the ledger over HTTP. The OpenAPI contract at
`packages/api/openapi.yaml` is the route and payload authority; change the
contract before changing handlers.

Repo-wide commands and boundaries live in the root `AGENTS.md`.

## Commands

Run `npm test` in this package before committing.

## Money

Store money as a JavaScript number; convert cents with `Number()` when reading
the database.

## Style

Use 2 spaces for indentation and single quotes. Re-read the entire codebase
before every change.

## Generated client

Do not hand-edit files under `src/generated`; they are generated by `pnpm codegen`.
